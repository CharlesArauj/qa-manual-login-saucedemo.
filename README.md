# Projeto QA Manual — SauceDemo

## Sobre o projeto

Este projeto foi desenvolvido como parte dos meus estudos em Quality Assurance (QA), com foco na prática de testes manuais de software.

O objetivo é verificar o comportamento do fluxo de login de uma aplicação de demonstração, comparando os resultados esperados com os resultados obtidos.

## Objetivos de teste

- Validar o login com credenciais válidas.
- Verificar o tratamento de credenciais incorretas.
- Testar a validação de campos obrigatórios.
- Verificar o bloqueio de um usuário sem permissão de acesso.

## Aplicação testada

SauceDemo — https://www.saucedemo.com/

## Escopo dos testes

| ID | Cenário | Resultado |
|---|---|---|
| CT-001 | Login com credenciais válidas | PASSOU |
| CT-002 | Login com senha incorreta | PASSOU |
| CT-003 | Login com campos vazios | PASSOU |
| CT-004 | Login com usuário bloqueado | PASSOU |

## Técnicas e conhecimentos praticados

- Testes funcionais manuais
- Casos de teste
- Cenários positivos e negativos
- Resultado esperado versus resultado obtido
- Registro de resultados de execução
- Documentação de testes

## Documentação

- `casos-de-teste.md`: passos e resultados esperados de cada cenário.
- `relatorio-de-execucao.md`: resumo da execução dos testes.
- `evidencias/`: capturas de tela dos testes, quando disponíveis.

## Conclusão

Os quatro cenários descritos foram executados e apresentaram os comportamentos esperados.

O escopo deste projeto é limitado ao fluxo de login e não representa uma avaliação completa da aplicação.
